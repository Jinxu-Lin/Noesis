# Noesis: AI-Agent 协作科研方法论

## 愿景
将科研全流程产品化，研究者作为"产品经理"，AI Agent 作为"工程团队"，
通过系统化的方法论和自动化工具，大幅提升科研效率。

## 核心理念
- 论文 = 产品，研究者 = PM + 全栈工程师
- AI Agent = 可调度的工程团队
- 科研流程 = 产品开发生命周期

## 项目结构
- `methodology.md` — 方法论主文档（high-level guide）
- `phases/` — 各阶段详细指南
- `skills/` — 可复用的 Claude Code Skills
- `subagents/` — SubAgent 模板
- `templates/` — 项目模板和 CLAUDE.md 模板
- `case-studies/` — 从用户实践中提炼的案例

## 状态
正在与用户共同构建中。基于真实科研项目经验提炼。
